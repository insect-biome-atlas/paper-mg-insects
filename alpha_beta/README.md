# alpha-beta
Repository for data, scripts and figures related to estimation of alpha and beta diversity

## R scripts
- `plot_combined.R`: plot species accumulation plots (alpha diversity) and spatial and temporal turnover for MG and SE in one figure
- `plot_beta_by_mg_forest.R`: plot spatial and temporal turnover for each mg forest type separately
- `plot_spatial_by_niche.R`: plot spatial turnover by niche for MG and SE
- `plot_temporal_by_niche.R`: plot temporal turnover by niche for MG and SE
- `functions.R`: common functions for turnover computations used by the above scripts
