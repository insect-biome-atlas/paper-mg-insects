# composition_accumulation

This repo contains scripts used to plot accumulation curves for faunal composition parameters

The main scripts are as follows:
- `prepare_data.R`
- `compute_niche_accumulation.R`
- `compute_habitat_accumulation.R`
- `compute_taxonomic_accumulation.R`
- `plot_niche_accumulation.R`
- `plot_habitat_accumulation.R`
- `plot_taxonomic_accumulation.R`
