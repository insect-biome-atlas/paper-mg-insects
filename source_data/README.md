# source_data
This directory contains source data regarding the expanded clades in the Chesters tree, and
the trait data coding for Sweden and Madagascar.

Generally speaking, csv exports of these files will be found in the relevant directory
under the directory `ref_tree` or `traits`, where further processing of the data will
be documented.

In some cases, the files here are xlsx versions of data generated by our scripts, used
to elicit feedback on generated taxonomy and traits data.

Then files are as follows:
 - `Expanded_Ichneumonidae_taxonomy.xlsx`: file used to elicit feedback on ichneumonid taxonomy generated by our scripts.
 - `Ichneumponidae_traits.xlsx`: Ichneumonidae lite history traits data
