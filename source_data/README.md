# source_data
This directory contains source data regarding the expanded clades in the Chesters tree, and
the trait data coding for Sweden and Madagascar.

Generally speaking, csv exports of these files will be found in the relevant directory
under the directory `ref_tree` or `traits`, where further processing of the data will
be documented.

In some cases, the files here are xlsx versions of data generated by our scripts, used
to elicit feedback on generated taxonomy and traits data.

The files are as follows:
 - `Expanded_Ichneumonidae_taxonomy.xlsx`: file used to elicit feedback on ichneumonid taxonomy generated by our scripts.
 - `Ichneumponidae_traits.xlsx`: Trait data for ichneumonids
 - `Braconidae_traits.xlsx`: Trait data for braconids
 - `Cecidomyiidae_MG_traits_readMJ.xlsx`: Original trait data for cecidomyiids from Lamarre, with comments from Mathias Jaschhof
 - `Cecidomyiidae_taxonomy_traits.xlsx`: Cecidomyiid taxonomy and trait data
 - `Chalcidoidea_life_history_trait_comments_JH.txt`: Comments from John Heraty on chalcidoid traits
 - `Chalcidoidea_life_history_traits.xlsx`: Trait data for chalcidoids
 - `Chesters_Braconidae_taxonomy_updated.xlsx`: Updated taxonomy for braconids in Chesters / Sundh et al
 - `Chesters_Chalcidoidea_taxonomy_updated.xlsx`: Updated taxonomy for chalcidoids in Chesters / Sundh et al
 - `Cruaud_et_al_Table_S1.xlsx`: Chalcidoid taxonomy data from Cruaud et al (2024), Table S1
 - `Cruaud_taxonomy_coi_min_bc_cov_300_seq_meta_updated.xlsx`: Feedback on taxonomy and traits for Cruaud et al (2024) taxa with COI data
 - `Entognatha_taxonomy_traits.xlsx`: Updated and expanded taxonomy and trait data for Entognatha, based on Table S1 in Bellini et al (2023)
 - `Expanded_Ichneumonidae_taxonomy.xlsx`: Updated and expanded taxonomy data for Ichneumonidae
 - `goodsell_SE_all_traits.csv`: Expanded trait data for Swedish fauna, covering most terrestrial arthropods
 - `Ichneumonidae_traits.xlsx`: Updated and expanded (more granular) trait data for Ichneumonidae
 - `MG_Hexapoda_Family_traits.xlsx`: Trait data for the Madagascan insect fauna, assembled for this project
 - `Ronquist_2020_SE_traits.xlsx`: Ronquist et al (2020) Table S1, with trait data for Swedish insect (hexapod) families
 - `trait_definitions.txt`: Trait definitions
