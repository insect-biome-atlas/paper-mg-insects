# chalcidoidea
Scripts and output data for generating a more diverse and accurate tree for Chalcidoidea

## Details
For Chalcidoidea, we started with the combined UCE and AHE tree presented by Cruaud at el (Cladistics, 2024). The taxon sampling data from the paper is in the `../source_data/` folder. The exported csv file is in this repo, `cruaud_et_al_taxon_sampling.csv`, and the combined tree is in the file `IQ_COMBINED.tre`.

The R script `check_cruaud_et_al_tree.R` checks the monophyly of genera in the Cruaud et al tree.

We first prepared the Cruaud et al taxonomy file:
 - `extract_cruaud_et_al_taxonomy.R`: Script to extract information from the tree and from the taxon sampling file
 - `cruaud_taxonomy.tsv`: The taxonomy file generated by the script

To assemble relevant COI data for the tips in the tree, we used the following scripts:
 - `gb_fxns.R`: Functions for retrieving sequence data from GenBank through the `rentrez` R package.
 - `search_chalcidoid_coi_seqs_ncbi.R`: Functions for retrieving COI sequences
 - `select_ref_seq_fxn.R`: Function for selecting the best COI reference sequence if several are available
 - `match_cruaud_with_coi_seqs.R`: Search for COI sequences matching the Cruaud et al tips
 - `add_cruaud_extra_coi_seqs.R`: Search for extra COI sequences not found by the original script

The searches were done in several steps. The output data are in the following files:
 - `cruaud_ncbi_coi_survey_steps1-3_log.txt`: log output from the scripts
 - `cruaud_ncbi_coi_survey_steps1-3.fasta`: FASTA file with the retrieved sequences
 - `cruaud_ncbi_coi_survey_steps1-3.tsv`: Metadata for the retrieved sequences, including alignment scores etc

For the alignment scores, we used an arbitrarily selected standard barcode sequence for a chalcidoid (genus Torymus).
The sequence is 652 bp long, which is the standard length in Chalcidoidea (they have a 6 bp deletion compared to most
other insects). The sequence is in the file `reference_barcode_Torymus_652.fasta` and the reference db output from
`vsearch`, which was used to obtain alignments, is in the file `ref.udb`. Alternative reference sequences that may
be of interest are in the folder `alt_reference_barcodes`.

The final matching is contained in and generated by the following files:
 - `cruaud_taxonomy_coi_min_bc_cov_300.tsv`: Extends the cruaud taxonomy file with GB accessions for the best reference sequences
 - `check_coi_extensions.R`: checks which COI sequences can be added depending on different filtering criteria (barcode coverage etc)
 - `combine_taxonomy_and_seq_meta.R`: Extends the cruaud taxonomy file with sequence metadata for the best reference sequences, given that GB accessions have been added
 - `cruaud_taxonomy_coi_min_bc_cov_300_seq_meta.tsv`: The file resulting from extending the taxonomy with the sequence metadata

## Reference
Cruaud, Astrid, Jean-Yves Rasplus, Junxia Zhang, et al. ‘The Chalcidoidea Bush of Life: Evolutionary History of a Massive Radiation of Minute Wasps’. Cladistics 40, no. 1 (2024): 34–63. https://doi.org/10.1111/cla.12561.
