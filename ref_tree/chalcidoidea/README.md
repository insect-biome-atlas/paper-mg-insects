# chalcidoidea
Scripts and output data for generating a more diverse and accurate tree for Chalcidoidea

## Details
For Chalcidoidea, we started with the combined UCE and AHE tree presented by Cruaud at el (Cladistics, 2024). The taxon sampling data from the paper is in the `../source_data/` folder. The exported csv file is in this repo, `cruaud_et_al_taxon_sampling.csv`, and the combined tree is in the file `IQ_COMBINED.tre`.

The R script `check_cruaud_et_al_tree.R` checks the monophyly of genera in the Cruaud et al tree.

We first prepared the Cruaud et al taxonomy file:
 - `extract_cruaud_et_al_taxonomy.R`: Script to extract information from the tree and from the taxon sampling file
 - `cruaud_taxonomy.tsv`: The taxonomy file generated by the script

To assemble relevant COI data for the tips in the tree, we used the following scripts:
 - `gb_fxns.R`: Functions for retrieving sequence data from GenBank through the `rentrez` R package.
 - `select_ref_seq_fxn.R`: Function for selecting the best COI reference sequence if several are available
 - `match_cruaud_with_coi_seqs.R`: Search for COI sequences matching the Cruaud et al tips
 - `add_cruaud_extra_coi_seqs.R`: Search for extra COI sequences not found by the previous script

The searches were done in several steps using the above scripts. The output data are in the following files:
 - `cruaud_ncbi_coi_survey_steps1-4_log.txt`: log output from the scripts
 - `cruaud_ncbi_coi_survey_steps1-4.fasta`: FASTA file with the retrieved sequences
 - `cruaud_ncbi_coi_survey_steps1-4.tsv`: Metadata for the retrieved sequences, including alignment scores etc

For the alignment scores, we used an arbitrarily selected standard barcode sequence for a chalcidoid (genus Torymus).
The sequence is 652 bp long, which is the standard length in Chalcidoidea (they have a 6 bp deletion compared to most
other insects). The sequence is in the file `reference_barcode_Torymus_652.fasta` and the reference db output from
`vsearch`, which was used to obtain alignments, is in the file `ref.udb`. Alternative reference sequences that may
be of interest are in the directory `reference_barcodes`.

The final matching is contained in and generated by the following files:
 - `cruaud_taxonomy_coi_min_bc_cov_300.tsv`: Extends the cruaud taxonomy file with GB accessions for the best reference sequences
 - `check_coi_extensions.R`: checks which COI sequences can be added depending on different filtering criteria (barcode coverage etc)
 - `combine_taxonomy_and_seq_meta.R`: Extends the cruaud taxonomy file with sequence metadata for the best reference sequences, given that GB accessions have been added
 - `cruaud_taxonomy_coi_min_bc_cov_300_seq_meta.tsv`: The file resulting from extending the taxonomy with the sequence metadata 

Feedback on the Cruaud extensions and updates with clade info and initial life history data (see also `source_data` directory):
 - `cruaud_taxonomy_coi_min_bc_cov_300_seq_meta_updated.tsv`

Finally, the results are synthesized into sequence, taxonomy and tree files matching the Cruaud et al tips as much as possible.
 - `generate_cruaud_co1_data.R`: Script synthesizing the data
 - `cruaud_CO1_taxonomy.tsv`: Taxonomy
 - `cruaud_CO1.fasta`: Sequences
 - `cruaud_CO1.nwk`: Tree

The chalcidoid sequences in the Chesters tree, taken from the Sundh et al (2024) analysis, are extracted using the code in the `chesters_2017` directory. The taxonomy information was updated using the manually edited file (the original Excel file is in the 'source_data' directory).
The Chesters data include the outgroup Mymarommatidae, as the outgroup sequences are of particular interest.
 - `chesters_chalcidoidea_taxonomy.tsv`: Taxonomy
 - `chesters_chalcidoidea.fasta`: Sequences
 - `chesters_chalcidoidea.nwk`: Tree
 - `chesters_chalcidoidea_taxonomy_updated.csv`: manually updated taxonomy annotations for the chesters/sundh et al chalcidoidea sequences

The input files for the MrBayes analyses are generated by the following scripts:
 - `make_mb_data.sh`: shell script directing the generation
 - `merge_chalcidoidea_data.R`: merging Chesters and Cruaud data
 - `generate_chalcidoida_nexus_files.R`: generating Nexus data and constraint files

The following files are generated:
 - `alignments` directory: temporary alignment files
 - `expanded_chalcidoidea_taxonomy`: Taxonomy file
 - `expanded_chalcidoidea.fasta`: Sequences
 - `mb_runs/chalcidoidea.nex`: Nexus data file
 - `mb_runs/cruaud_constraints.nex`: Cruaud tree as soft constraints
 - `mb_runs/higher_constraints.nex`: Ingroup-outgroup separation and clade constraints implemented as hard constraints

NB! In assembling the final tree, a tree sample from `mb_runs/run3/` was used. There was a minor edit to one of the tip labels after the runs were completed. The tip labels in the tree sample file from this run were post-edited to reflect the minor tip label edit (Tetrapus_n. -> Tetrapus_sp).
 
## Reference
Cruaud, Astrid, Jean-Yves Rasplus, Junxia Zhang, et al. ‘The Chalcidoidea Bush of Life: Evolutionary History of a Massive Radiation of Minute Wasps’. Cladistics 40, no. 1 (2024): 34–63. https://doi.org/10.1111/cla.12561.
